# 🧠 مغز دوم · Second Brain

داشبورد شخصی برای مدیریت همه ابعاد زندگی، بر پایه روش‌های PARA و CODE (تیاگو فورته).

## اجرا
- **روی لپ‌تاپ:** فایل `index.html` رو با Chrome یا Edge باز کن.
- **روی گوشی:** بعد از انتشار روی GitHub Pages، لینک رو باز کن و «Add to Home Screen» رو بزن.

## همگام‌سازی ابری (Supabase)
1. فایل `supabase-setup.sql` رو یک بار در Supabase → SQL Editor اجرا کن.
2. توی برنامه برو به تنظیمات → همگام‌سازی ابری → ساخت حساب / ورود.
3. روی دستگاه دوم هم با همون حساب وارد شو. از اون به بعد همه چیز لحظه‌ای همگام می‌شه.
